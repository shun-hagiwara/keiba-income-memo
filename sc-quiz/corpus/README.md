# SC午後過去問：出典確認済み短答データ

## 収録範囲（2026-11-20）

- **28件：原試験で用語・名称・短い字句を直接答える形式の設問**。選択肢の記号だけを答える問題や、理由・対策を文章で説明する問題を短答化していません。
- **10件：過去問学習を横断した重要知識の復習**。こちらは公式の短答問題ではなく、独自に設計した総合復習カードです。
- **13組のIPA公式「問題PDF／解答例PDF」への出典インデックス**をJSON内に保持しています（資料をすべてテキスト化したという意味ではありません）。
- 旧情報セキュリティスペシャリストを含む古い年度を中心に収録。解答済みと分かっている直近年度の問題は優先していません。

- [スマホ復習ページ](../index.html) : 上記JSONを取得して表示。文字入力なし、タップして答えを表示。
- [以前の50問版](../legacy.html) : 原設問の形式を満たさない問題も含んでいたので、主教材から外して保存。

## 原文との区別

`ipa_answer` はIPA公式解答例に示された短い正答の表記です。複数の正解表現があり得ます。

`question` は学習時に一目で読めるように**原設問の文脈を短く再構成した文章**であり、IPA問題文の逐語転載ではありません。正確な原設問と前提条件は、`paper_id` から `papers[].question_pdf` を参照してください。

`location` は設問・空欄の対応を示します。`kind=short` は**元の問題に直接短く答える空欄／名称指定が存在した**問題、`kind=priority` は過去問横断の独自復習です。

書き換えた設問文が原題と違う意味になっていないかを追加レビューする際は、公式問題PDFの該当設問・本文の空欄・公式解答例を1対1で照合してください。

## 選定時に除外する例

「なぜか、理由を30字以内で述べよ」「改善策を50字で具体的に述べよ」「対策を二つ説明せよ」のような記述問題は、**模範解答に専門用語が含まれても短答問題にはしない**。元の試験が番号・選択肢記号のみを要求する問題も、知識用語の短答として作り変えない。

## 検証と今後の拡張のためのデータ項目

- `paper_id` と `location` : 同じ概念が別年度で繰り返された場合でも原題を混同しないためのキー。
- `question_mode` : 原設問の回答形式。
- `rendering` : 学習用に変更した文章であることの明示。
- `ipa_answer` : 公式解答と照合した値。
- `explanation`・`diagram`・`contrast`・`memory` : 独自の説明・因果図・類似用語・覚え方。

**注意：** 現段階の成果物は「精査対象の機械可読カードと公式原典への索引」であって、10年分すべての試験問題本文を完全OCR・校訂した全文コーパスではありません。PDFの図表・設問文全体の完全移植は行っていません。この点を偽って出典に基づく推論をしないこと。
