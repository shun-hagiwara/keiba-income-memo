# SC午後・コード読解を除いた用語復習

## 現在の収録内容（2026-11-20）

- **40問：元の過去問で用語・名称・短い字句を答える設問**。学習しやすいように問題文だけ短く再構成しています。
- **10件：頻出知識を結び付けた独自復習**。IPAの「短答問題そのもの」とは区別します。
- **18組のIPA公式「問題PDF」「解答例PDF」の索引**。2016〜2022年の旧情報セキュリティスペシャリスト試験・情報処理安全確保支援士試験を参照。
- 実際に解いた記録がある近年の問題の重複を抑え、主に2016〜2021年から選定しました。

## 採用・除外の基準

- **採用：** IPA解答例が、用語・名称・略称・短い技術的な字句である設問。DNS、メール、暗号、PKI、ネットワーク、認証、インシデント対応など。
- **除外：** Webアプリのソースコードを読解する問題、C言語のメモリ操作を読む問題、シェル・コマンドの処理読解が主な問題。
- **除外：** 原問が多肢選択（記号だけを選択）、長文の理由・設計・対処方法の記述であるものを無理に短答化すること。

## ファイルの役割

- [スマホ用の一問一答](../index.html)：入力不要。「答えを見る」→「覚えた／曖昧／間違えた」。解答回数・誤答回数を同一ブラウザ内に保存。
- [機械可読カードデータ](../data/reviewed-questions.json)：`papers[]` で試験の原典、`cards[]` でカードを管理。
- [旧50問版](../legacy.html)：前の版を記録として保存。現行の学習履歴とは別管理。

### JSONの主なフィールド

| フィールド | 意味 |
|---|---|
| `paper_id` | 出典の年度・期・試験区分を指すキー |
| `location` | 問・設問・空欄記号 |
| `ipa_answer` | IPA解答例の短い正答表現 |
| `question` | 学習用に再構成した短い問い（原文ではない） |
| `explanation`, `diagram` | 原理の説明・因果フロー |
| `contrast`, `memory`, `formal` | 比較用語・覚え方・正式名称 |
| `kind` | `short`＝短答カード、`priority`＝独自重要知識 |

## 出典に関する注意

**このリポジトリは過去問全文のデータベースではありません。** 元の設問全文・図表は公式問題PDFで確認してください。カードの設問文・解説・模式図は学習用に編集した文章です。原典の事実と解答以外はIPAが保証した内容ではありません。

出典：独立行政法人情報処理推進機構（IPA）、情報セキュリティスペシャリスト試験・情報処理安全確保支援士試験の公表問題および解答例。詳細は `papers[]` 内のURLを参照。

公表過去問の利用条件は、[IPA公式FAQ](https://www.ipa.go.jp/shiken/faq.html)を確認してください。
