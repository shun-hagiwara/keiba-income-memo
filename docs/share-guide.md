# 競馬収支メモを使い始める方へ

この資料は、競馬収支メモを初めて使う方向けの手順です。

アプリのURLを開くだけで使い始められます。自分の収支データは、自分の端末または自分のGoogle Driveに保存されます。アプリの作成者のデータが見えることはありません。

## まず知っておくこと

- このアプリは、SPAT4の投票内容照会画面のスクリーンショットを読み取り、競馬収支を記録するWebアプリです。
- SPAT4やJRAのログインID、パスワード、暗証番号は入力しません。
- 投票サイトへ自動ログインしたり、自動投票したりする機能はありません。
- 画像の読み取りはブラウザ内で行います。
- データは、最初は使っている端末のブラウザ内に保存されます。
- Google Driveに保存したい場合は、自分のGoogleアカウントでログインします。

## 用意するもの

- iPhone、Android、またはPC
- ChromeまたはSafariなどのブラウザ
- Google Drive保存を使う場合は、自分のGoogleアカウント
- SPAT4の投票内容照会画面のスクリーンショット

## 使い始める手順

1. アプリのURLを開きます。
2. 画面が表示されたら、そのまま利用できます。
3. Google Driveに保存したい場合は、画面内の「Googleログイン」を押します。
4. 自分のGoogleアカウントでログインします。
5. 「このアプリがGoogle Driveのファイルを作成・読み書きすること」を許可します。
6. 以後、「Driveへ保存」「Driveから読込」を使えるようになります。

## iPhoneで画像を取り込む手順

1. iPhoneでSPAT4を開き、投票内容照会画面を表示します。
2. スクリーンショットを撮ります。
3. 競馬収支メモをブラウザで開きます。
4. 「画像を選択」または「画像をアップロード」を押します。
5. フォトライブラリから、先ほど撮ったスクリーンショットを選びます。
6. 画像が表示されたら、OCR読み取りを実行します。
7. 読み取り候補を確認します。
8. 日付、競馬場、レース番号、式別、買い目、購入金額、払戻金額などを確認します。
9. 間違いがあれば手で修正します。
10. 問題なければ保存します。

## Google Driveに保存する手順

1. Googleログインします。
2. 記録を保存したあと、「Driveへ保存」を押します。
3. 自分のGoogle Driveに `KeibaMemo` フォルダが作られます。
4. その中に `records.json` という保存ファイルが作られます。

別の端末で使う場合は、同じGoogleアカウントでログインして「Driveから読込」を押します。

## データの保存場所

```text
アプリ本体
  GitHub Pages上に公開されています。

入力した収支データ
  1. 端末のブラウザ内のlocalStorage
  2. Google Driveへ保存した場合は、自分のGoogle Drive内のKeibaMemo/records.json
```

アプリのURLは公開されていますが、あなたのGoogle Driveの中身が他の人に見えるわけではありません。他の人がアプリを開いた場合、その人自身のブラウザ保存またはGoogle Drive保存が使われます。

## ホーム画面に追加する方法 iPhone

1. SafariでアプリURLを開きます。
2. 画面下の共有ボタンを押します。
3. 「ホーム画面に追加」を押します。
4. 名前を確認して「追加」を押します。

これで、ホーム画面からアプリのように起動できます。

## よくある質問

### URLを知っている人は、自分のデータを見られますか？

見られません。アプリの画面自体は誰でも開けますが、保存データは各自の端末または各自のGoogle Driveに保存されます。

### Googleログインしないと使えませんか？

使えます。ただし、その場合は基本的にその端末のブラウザ内に保存されます。端末を変えて使いたい場合やバックアップしたい場合は、Google Drive保存を使ってください。

### 毎回Googleログインが必要ですか？

Googleの認証トークンには期限があります。ページを開き直したときや保存時に、再ログインが必要になることがあります。

### OCR結果が間違っている場合はどうすればいいですか？

保存前に手で修正してください。スクリーンショットの文字が小さい、画面の一部が切れている、画像が暗い場合は誤認識しやすくなります。

### 競馬場やレース番号が読み取れない場合はどうすればいいですか？

保存前に手入力してください。可能であれば、スクリーンショットに競馬場名とレース番号が写るように撮ると読み取りやすくなります。

### 画像は外部サーバーへ送られますか？

このアプリでは、投票画像そのものをアプリ専用サーバーへ送る構成にはしていません。OCRはブラウザ内で行います。ただし、OCRライブラリなどの外部ファイルはCDNから読み込まれる場合があります。

## 配布する人向けメモ

人に渡すときは、以下を伝えてください。

```text
このURLを開いて使ってください。
保存データはあなた自身の端末またはあなた自身のGoogle Driveに保存されます。
Google Drive保存を使う場合は、自分のGoogleアカウントでログインしてください。
```

Google CloudのOAuth同意画面がテスト状態の場合、利用者のGoogleメールアドレスをテストユーザーに追加する必要があります。ログインで拒否される場合は、アプリ管理者にGoogleメールアドレスを伝えてください。
